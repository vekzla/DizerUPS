Legend — UPS Status Codes

OLOn Line — running from mains power (normal).
OBOn Battery — mains lost, running from battery.
LBLow Battery — charge critically low.
CHRGCharging — battery is replenishing.
DISCHRGDischarging — battery is supplying the load.
RBReplace Battery — battery failed self-test.
OVEROverload — load exceeds UPS capacity.
FSDForced Shutdown — shutdown in progress.
OFFOutput Off — UPS output is disabled.

How the Values Are Calculated

Real power (Watts) — your UPS reports load as a percentage, so power is derived from nominal power based on model being 720W: power = (ups.load / 100) × ups.realpower.nominal example: (15 / 100) × 720 = 108 W
Input / Load current (Amps) — derived from power and the measured voltage (P = V × I): current = power / voltage example: 108 / 246 ≈ 0.44 A
Battery current (Amps) — only while discharging (status DISCHRG/OB); 0 A while On Line: battery_current = power / battery.voltage (when discharging) example on battery: 108 / 28.2 ≈ 3.83 A
Frequency (Hz) — some CyberPower units report deci-Hertz; values > 100 are divided by 10: example: 498.0 → 49.8 Hz
